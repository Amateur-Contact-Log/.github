## Inside Amateur Contact Log

Amateur Contact Log is a local Windows amateur logger with a named contact desk, a short call list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside a log you already own and holds only the call that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra QSOs wait for their own title. Amateur Contact Log starts with a local profile and does not need a complex account system.

The contact desk stays on a log you already keep. Untitled QSOs stay off the live list.
